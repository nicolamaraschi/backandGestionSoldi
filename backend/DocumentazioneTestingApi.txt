# API Testing Documentation

## Authentication
```bash
# Register a new user
curl -X POST -H "Content-Type: application/json" -d '{"email":"test@example.com","password":"password123","name":"Test User"}' http://localhost:3000/api/auth/register

# Login
curl -X POST -H "Content-Type: application/json" -d '{"email":"test@example.com","password":"password123"}' http://localhost:3000/api/auth/login

# Logout
curl -X POST -H "x-auth-token: YOUR_TOKEN_HERE" http://localhost:3000/api/auth/logout
```

## Categories
```bash
# Create a new category
curl -X POST -H "Content-Type: application/json" -H "x-auth-token: YOUR_TOKEN_HERE" -d '{"name":"Stipendio","type":"income"}' http://localhost:3000/api/categories

# Get all categories
curl -H "x-auth-token: YOUR_TOKEN_HERE" http://localhost:3000/api/categories

# Update a category
curl -X PUT -H "Content-Type: application/json" -H "x-auth-token: YOUR_TOKEN_HERE" -d '{"name":"Salario","type":"income"}' http://localhost:3000/api/categories/CATEGORY_ID

# Delete a category
curl -X DELETE -H "x-auth-token: YOUR_TOKEN_HERE" http://localhost:3000/api/categories/CATEGORY_ID
```


## Notes
1. Replace `YOUR_TOKEN_HERE` with the JWT token received from the login or register API
2. Replace `CATEGORY_ID`, `MOVEMENT_ID`, `GOAL_ID`, `BUDGET_ID`, and `NOTIFICATION_ID` with the respective IDs received when creating these resources
3. The token expires after 1 hour, after which you'll need to login again to get a new token
